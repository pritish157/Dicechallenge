# 🎲 Dice Challenge

A lightweight browser-based Dice Challenge game built using JavaScript. The app simulates a two-player dice roll and dynamically determines the winner on each refresh.

---

## 🚀 Live Demo

👉https://pritish157.github.io/Dicechallenge/

---

## ⚙️ Tech Stack

* HTML5
* CSS3
* JavaScript 

---


## 🧩 How It Works

* Two dice are generated using JavaScript’s random number logic
* Each refresh triggers a new roll
* The app compares both values and declares:

  * Player 1 wins
  * Player 2 wins
  * Draw
